# stzbHelper

率土之滨桌面助手（Windows 端）。

通过 Npcap 抓取游戏客户端网络包，自动获取同盟成员、战报、武勋、攻城等数据，提供考勤统计、队伍分析、同盟管理、AI 查询等一体化功能。

## 功能简介

- **攻城考勤** — 新建任务后翻阅目标城池战报，自动统计出勤
- **队伍分析** — 队伍查询、队伍胜率、队伍克制分析、热门排行
- **同盟管理** — 成员同步、同盟战报（自动翻阅与导出）、分组武勋、赛季看板、活跃度分析
- **妲己小秘书（AI 助手）** — 用自然语言查询同盟数据

## 如何使用

### 1. 安装依赖

- **Node.js**：到 https://nodejs.org/ 下载，不需要自行构建时可不用直接下载Npcap就可以直接运行程序
- **Npcap**： https://npcap.com/#download 下载，安装时**必须勾选 "Install in WinPcap API-compatible Mode"**

### 2. 启动程序

右键 `run.bat` → **以管理员身份运行**，脚本会自动安装依赖、编译并启动程序。

### 3. 首次使用

1. 启动后进入「选择数据库」页，点 **创建数据库**，输入角色名与服务器
2. 在游戏内打开自己的 **主公簿**，程序会自动绑定 IP 并开始抓取数据

### 4. 常用操作

- **同步成员**：「同盟成员」页 → 点同步成员 → 在游戏内打开同盟成员列表
- **攻城考勤**：「攻城任务」页 → 新建任务 → 开始考勤 → 在游戏内翻阅目标城池的同盟战报 → 点统计查看结果
- **队伍查询**：「队伍查询」页输入玩家名或同盟名（需先开启「获取战报详情」并在游戏内查看过战报详情）
- **自动翻阅战报**：「同盟战报」页设置截止时间，由程序自动翻页抓取
