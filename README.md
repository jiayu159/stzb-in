## 使用说明
本程序依赖于 [Npcap](https://npcap.com/#download) 抓取网络数据包来获取战报与同盟成员信息, 所以你在使用前需要先安装Npcap(https://npcap.com/dist/npcap-1.82.exe)  
## 支持情况
- PC客户端
- 模拟器移动端客户端
- 移动端客户端（使用移动端设备时需运行本程序的主机带有无线网卡，并打开移动热点给移动端设备连接）
## 功能
- 攻城任务考勤（统计目标成员的主力，拆迁队伍数量和攻城次数）
- 分组周武勋
- 队伍查询（通过同盟战报记录队伍）
## 构建
1. 构建前需确保已安装 golang 1.24及以上版本、nodejs  
2. `go install github.com/wailsapp/wails/v2/cmd/wails@latest`
3. `wails build`

## 近期更新（stzbHelper-add 分支）

### 自动翻阅
- 支持两种模式：**鼠标模式**（屏幕中央引导框+滚轮翻页）与 **ADB模拟器模式**（通过 adb 连接雷电/MuMu/夜神等模拟器自动滑动翻页，可后台运行，不占用鼠标）
- 战报识别/截止时间/到底判断均基于 npcap 抓包数据
- 翻页间隔可在界面自定义（默认 600ms）

### 战报查询筛选
- **战斗类型筛选**：进攻（我盟进攻）/ 防守（我盟防守）/ 全部，以当前同盟为参照
- 当前同盟自动从同盟成员数据推断（成员参战战报中出现最多的同盟），可手动修改并记忆
- **主对象兵力筛选**：针对当前同盟参战方兵力过滤，可与战斗类型叠加

### 其他改动
- 攻城任务：城池分配助手（根据成员坐标距离推荐候选城市）
- "获取详细战报"开关移至战报页
- 删除战役叫阵入口
- 队伍查询/胜率查询去掉 idu 过滤
- 分组武勋页：每个指标支持升序/降序页内排序
- 免翻页直连拉取：开发中（界面已标注"还在开发中"）
